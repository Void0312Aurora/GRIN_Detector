## 1. 装置定位

当前反射分支使用的观测系统，属于四川大学提出的**弱测量差分成像（weak-measurement differential imaging）**方案族。其核心不是常规亮场显微成像，而是：

1. 用偏振态作为辅助自由度（ancilla）做**预选择**；
2. 用弱剪切耦合把样本横向梯度信息写入偏振；
3. 在**正交后选择**端口（暗口）读出近似正比于横向梯度的场。

当前 24 帧 BMP 采自**后选择暗口**；后续计划采集双轴剪切差分通道 `I_x` / `I_y`。

### 2.1 各功能块说明

| 功能块 | 作用 | 对本项目的含义 |
| --- | --- | --- |
| 光源 | 窄带相干照明 | 带宽 2 nm → 相干长度约 135 µm；暗口斑点/局部干涉受控 |
| 预选择 | 固定入射偏振 | 设定“未耦合”基准态 |
| 物镜 + 管镜 | 收集前表面反射场并成像 | NA 限制可接收斜率；倍率决定 `µm/px` |
| 弱剪切耦合 | 两正交偏振分量获得横向相对位移 δ | 暗口输出近似 ∝ ∂E/∂r_d |
| 后选择 | 投影到与预选择近正交的偏振 | **暗口**：光滑缓变场被抑制；边缘/缺陷/散射被放大 |
| 相机 | 线性 BMP 强度读出 | 固定曝光；光子传递约 0.46 DN/e⁻ |

### 2.2 弱剪切耦合的物理图像

设样本在像面（或中间像面）的复场为 `E(r)`。弱剪切把两个正交偏振分量分别平移 ±δ/2：

```text
E_↑(r) ≈ E(r − δ/2) · |↑⟩
E_↓(r) ≈ E(r + δ/2) · |↓⟩
```

若预选择为对称叠加，后选择取正交组合，则暗口复振幅近似为：

```text
E_dark(r) ≈ E(r − δ/2) − E(r + δ/2) + ε E(r)
         ≈ −δ · ∂E/∂r_d + ε E(r)     （|δ| 很小、场缓变时）
```

其中：

- `δ`：剪切矢量（方向决定差分轴；当前单帧尚未标轴）；
- `ε`：后选择消光不完美引入的**相干泄漏**（理想正交时 ε = 0）。

因此：

- **光滑球冠内部**：反射场在 NA 接受范围内近似镜面、横向梯度极小 → 暗口接近暗场地板；
- **接缝、划痕、散射坑**：局部斜率/振幅突变 → 暗口发亮；
- **夹具粗糙背景**：空间高频散射 → 暗口保持明亮。

项目仿真中对应的是 `optical_leakage_lite` 的 `dark_port.mode = image_shear`：

```text
E_out = E(r + d/2) − E(r − d/2) + leak · E
I     = |E_out|²
```

`fourier_tilt` 形式（乘以 `2i sin(π q · r + φ)`）在绝对 DN 拟合中已被否决，不作工作模型。

## 3. 暗口观测的直观后果

1. **黑盘不是“吸收”，而是差分抑制**  
   光滑前表面在暗口几乎不贡献强度；黑盘半径对应可成像的球冠通光孔径边缘。

2. **缺陷对比度主要来自散射振幅，而非纯高度坑**  
   纯高度扰动在暗口的响应有上限；真实大异常（约 122–140 DN）需要局部散射振幅量级约 `|A| ≈ 0.22–0.27`（相对当前曝光标定）。

3. **接缝亮带是形貌的暗口渲染**  
   模压圆角/肩台/浅槽的坡度在暗口被画成环带，不是剪切干涉条纹。

4. **暗口强度对剪切二次压缩**  
   理想极限下 `I ∝ |δ ∂E/∂r|²`，光子预算紧张；当前帧为 rim 曝光、内部仅 2–6 DN。

```text
φ(r) = 4π n_air cosθ · h(r) / λ ,   θ = 0, n_air = 1
```

样本折射率**不进入**该几何高度→相位换算（前表面反射）。

### 4.2 工作尺度（内部证据采用；外部待复核）

| 项目 | 标称说法 | 工作采用值 | 依据摘要 |
| --- | ---: | ---: | --- |
| 有效倍率 | 9.09× | **13.56×** | 黑盘半径中位 620 px ↔ 孔径 109.7 µm |
| 物面尺度 | 0.264 µm/px | **0.177 µm/px** | `2.4 / 13.56` |
| 全帧视场（约） | 1445 × 963 µm | ≈ 970 × 645 µm | 按工作倍率重算 |
| 邻心距（约） | 355 µm @9.09× | **238 µm @13.56×** | 圆心间距约 1344 px；可用阵列 datasheet 一裁定夺 |

为何倾向 13.56×：

1. **球冠自校准**：620 px × 0.177 µm/px ≈ 109.7 µm，与几何孔径一致。  
2. **内部环检验**：若按 9.09× 把黑盘解释成更大 cell，则球冠边缘应出现在约 0.67 R；实测径向能量在 ρ∈[0.32, 0.84] 单调、最暗约在 0.68，亮环只在盘缘。  
3. **物镜族一致性**：NA 0.42 典型对应 20× / f≈10 mm（设计管长 200 mm）；配 **135 mm 管镜** → 13.5×，与自校准相差约 0.5%。`9.09 ≈ 200/22` 更像管长记账笔误，而非真实管长 90.9 mm。

外部复核建议（二选一即可）：

- 确认管镜焦距是否为 135 mm；  
- 或对照微透镜阵列节距 datasheet（238 µm vs 355 µm）。

## 6. 仍待实验室确认的事项

按对建模阻塞程度排序：

1. **倍率记账**：管镜焦距或阵列节距（工作值 13.56× 已内部收敛，此项为外部核实）。  
2. **剪切参考面与轴向约定**：书面确认“10 µm”指相机面；标明相对相机 x/y 的方向。  
3. **后选择消光比 / 故意偏置**：决定暗口相干泄漏地板，也可能关联固定照明偶极。  
4. **照明几何**：同轴落射 / 环形 / 斜入射及均匀性。  
5. **材料**：透镜折射率/前表面反射率、基板与夹具材料（振幅图物理化需要）。  
6. **差分实验协议**：同镜 clean/defect，或继续跨样本；`I_x`/`I_y` 同步方案。  
7. **曝光时间与模拟增益**（可选）：用于把 0.46 DN/e⁻ 升到绝对光子定标。

建议顺带采集：无样品平场、暗场、单镜不重装重复帧；以及 1–2 颗透镜的独立 WLI/轮廓仪形貌。

## 7. 简短原理公式备忘

弱耦合幺正（示意）：

```text
U = exp(−i k_d Â δ / 2)
```

`Â` 为偏振可观测量，`k_d` 为沿剪切方向的空间频率算符。后选择到与预选择正交的态 `|φ_f⟩` 后：

```text
⟨φ_f|U|φ_i⟩ ≈ −i (δ/2) ⟨φ_f|Â|φ_i⟩ k_d   （一阶弱值展开）
```

成像语言下即得到 §2.2 的差分形式。强度

```text
I_dark ≈ |δ ∂E/∂r_d + ε E|²
```

在 `ε→0` 且 `δ` 小时，光滑区被压到相机暗噪声以下——这正是当前 24 帧“黑盘 + 亮缺陷/接缝”外观的直接原因。
